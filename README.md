> Um agregador de links pessoal desenvolvido durante os meus estudos de Front-end, focado em reunir todas as minhas redes profissionais e principais conexões num único lugar de forma limpa, moderna e responsiva.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização moderna, variáveis customizadas, Dark Mode e responsividade.
- **JavaScript**: Lógica para alternar entre os modos claro e escuro (Light/Dark Mode).
- **Git & GitHub**: Controlo de versão e hospedagem do código.

---

## ✨ Funcionalidades

- **Dark Mode Nativo**: Alternância fluida de tema com persistência visual.
- **Design Responsivo**: Adaptado para visualização perfeita em dispositivos móveis e desktops.
- **Links Personalizados**: Acesso rápido ao GitHub, LinkedIn, Instagram e outras redes.
