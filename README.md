## 🚀 Sobre o Projeto

O **DevLinks** é uma página centralizadora de links estilo "Linktree". O projeto foi construído com foco em design limpo, responsividade e na implementação de um sistema de alternância entre os modos **Light** (Claro) e **Dark** (Escuro).

---

## 🛠️ Tecnologias Utilizadas

Este projeto utiliza as seguintes tecnologias:

- **HTML5**: Estruturação semântica.
- **CSS3**: Estilização com variáveis customizadas, Flexbox e suporte a temas.
- **JavaScript**: Manipulação do DOM para alternância dinâmica de tema.
- **Git & GitHub**: Controle de versão e hospedagem.

---

## 🎯 Funcionalidades

- **Modo Dark / Light:** Alternância de tema fluida.
- **Design Responsivo:** Adaptado para diferentes tamanhos de tela (mobile e desktop).
- **Estrutura Modular:** Fácil personalização de links e ícones sociais.
